# 明日方舟助手

基于森空岛 API 的 AstrBot 插件，用于绑定森空岛账号并查询明日方舟基础玩家信息。

## 功能

- 绑定森空岛账号并保存查询所需凭据。
- 查询明日方舟角色基础信息。
- 生成基础信息卡片。
- 展示等级、注册日期、主线进度、渠道、理智恢复时间、干员数、时装数。
- 展示最多 3 个助战干员的等级、潜能、技能和模组信息。
- 查询集成战略肉鸽战绩，并生成包含主题封面、汇总数据、最近探索和生涯累计的大图。
- 支持「沉沦者的黑流树海」，展示行动力、徒步、加工品移动、居民据点、零件售卖和理想域统计。
- 当图片渲染服务不可用时，自动返回文字版查询结果。

## 命令

```text
/绑定账号 手机号 密码
/查询基础信息
/查询肉鸽 [傀影|水月|萨米|萨卡兹|岁|黑流树海|topicId]
/帮助
```

绑定示例：

```text
/绑定账号 13800138000 your_password
```

查询示例：

```text
/查询基础信息
```

肉鸽查询示例：

```text
/查询肉鸽
/查询肉鸽 黑流树海
/查询肉鸽 沉沦者的黑流树海
/查询肉鸽 rogue_6
/查询肉鸽 萨米
/查询肉鸽 rogue_4
```

不传主题时默认查询「沉沦者的黑流树海」。支持别名「黑流」「树海」「沉沦者」，旧主题的简称和完整名称仍然可用。

## 数据来源

插件通过鹰角账号登录获取森空岛凭据，然后调用森空岛接口查询已绑定的明日方舟角色信息。

当前使用的数据主要来自：

- 角色绑定列表
- 玩家基础信息
- 理智状态
- 干员和时装统计
- 助战干员信息
- 集成战略肉鸽主题封面、最近探索记录、生涯累计和偏好统计

## 隐私说明

绑定命令会使用森空岛账号手机号和密码登录。插件不会保存密码，只会保存后续查询所需的森空岛凭据、角色 UID、昵称和渠道信息。

建议在私聊中使用绑定命令，避免账号密码暴露在群聊中。如果已经在截图或群聊中泄露密码，请及时修改森空岛或鹰角账号密码。

## 常见问题

### 提示图片渲染服务不可用

这通常不是森空岛查询失败，而是 AstrBot 使用的 T2I 图片渲染服务返回错误。插件会自动返回文字版查询结果。

### 提示森空岛请求异常

请确认插件版本已包含森空岛签名请求头逻辑。森空岛业务接口需要 `sign`、`timestamp` 等请求头，仅携带 `cred` 无法稳定查询。

### 绑定成功但查询不到信息

请确认森空岛账号已经绑定明日方舟角色，并且使用的是当前 QQ 账号对应的 AstrBot 会话。

### 肉鸽查询主题不正确

`/查询肉鸽` 默认查询「沉沦者的黑流树海」（`rogue_6`）。也可以传入主题名或原始 `topicId`，例如 `/查询肉鸽 萨米`、`/查询肉鸽 岁` 或 `/查询肉鸽 rogue_3`。森空岛接口会同时返回全部肉鸽主题封面，插件会在图片中展示这些主题，并高亮当前查询主题。如果接口返回的主题与请求不符，插件会提示重试。

新版主题和字段对照森空岛[官方战绩页](https://game.skland.com/arknights/game-record)的公开前端实现。主题介绍见[黑流树海官方网站](https://ak.hypergryph.com/is/blackflowofdrowningseekers)。

### 肉鸽查询没有最近探索记录

该主题可能还没有游玩记录，或森空岛尚未同步数据。插件仍会展示已返回的主题统计，并给出无记录提示。偏好统计中标注「全服」的数据来自森空岛全服统计，并非个人偏好。

### 提示读取账号绑定数据失败

请检查 `Arknight_name_data.json` 是否为有效 JSON 对象。插件会保留损坏文件，避免重新绑定时覆盖其他账号的数据。空文件可正常开始绑定；后续保存使用原子替换，避免写入中断损坏原文件。

## 开发说明

插件入口为 `main.py`，常量和 HTML 卡片模板位于 `config.py`。

回归测试不需要登录森空岛或启动 AstrBot：

```bash
python -m unittest discover -s tests -v
ruff format .
ruff check .
```
